# Pathfinder AI

A full-stack career guidance website for Pathfinder. The React/Vite frontend presents services, testimonials, a career library, and a contact form. The Node.js/Express backend handles form submissions via Nodemailer with Google reCAPTCHA v2 protection. Deployed on Vercel (frontend static) with SQLite for optional data persistence.

## Tech Stack

### Frontend
- **Language:** TypeScript
- **Framework:** React 18 + Vite 5 (SWC)
- **Routing:** React Router DOM v6
- **UI:** shadcn/ui (Radix UI + Tailwind CSS v3), Framer Motion
- **Forms:** React Hook Form + Zod + EmailJS
- **Data fetching:** TanStack Query v5, Axios

### Backend
- **Runtime:** Node.js
- **Framework:** Express 5
- **Email:** Nodemailer
- **Security:** Google reCAPTCHA v2, CORS
- **Database:** SQLite (sqlite + sqlite3)

## Setup

```bash
npm install
# Copy .env.example (if present) or create .env:
# PORT=5000
# EMAIL_USER=your@email.com
# EMAIL_PASS=your_password
# RECAPTCHA_SECRET_KEY=your_recaptcha_secret
# VITE_RECAPTCHA_SITE_KEY=your_recaptcha_site_key
```

## Build / Run / Test

```bash
# Run frontend + backend together (recommended for development)
npm start
# Vite dev server: http://localhost:8080
# Express backend: http://localhost:5000

# Frontend only
npm run dev

# Backend only
npm run start:backend

# Production build
npm run build

# Preview production build
npm run preview

# Lint
npm run lint
```

## Architecture & Key Files

- `app.js` — Express entry point; mounts `formRoutes.js`, serves static files in production.
- `formRoutes.js` — POST `/api/contact` route: validates reCAPTCHA, sends email via `emailService.js`.
- `emailService.js` — Nodemailer transport configuration; reads credentials from env.
- Frontend calls the backend at `http://localhost:5000/api/...` in dev; update CORS origin in `app.js` for production.
- `vercel.json` — deploys only the Vite static build to Vercel; the Express backend must be hosted separately (e.g., Railway) for production contact form to work.
- `EMAILJS_SETUP.md` — documents the EmailJS alternative integration (also present in the frontend via `@emailjs/browser`).

## Conventions & Notes for Agents

- Path alias `@/` maps to `src/` (`tsconfig.app.json` + `vite.config.ts`).
- `components/ui/` is auto-generated by shadcn/ui CLI — do not edit by hand.
- Environment variables: backend reads from `.env` via `dotenv`; frontend reads `VITE_*` vars at build time.
- `LazyLayout.jsx` is a `.jsx` file (not `.tsx`) — this is intentional legacy; prefer `.tsx` for new components.
- `dist.zip` is a pre-built artifact — do not commit updated versions; regenerate with `npm run build`.
- `lovable-tagger` is a required dev dependency for the Lovable.dev platform — do not remove it.
- No automated test suite; verify changes with `npm start`.
